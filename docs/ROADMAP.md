## v1.1 — Planejado

Ideias para a próxima versão:

### Funcionalidades
- 🔍 **Busca no histórico** — Pesquisar conversas passadas
- 📊 **Estatísticas de uso** — Tokens gastos, tempo de resposta
- 🌙 **Modo escuro adicional** — Mais temas visuais
- 🔄 **Atualização automática** — Check de versão na inicialização
- 🎛️ **Controle granular de ferramentas** — Ativar/desativar individualmente

### Melhorias
- Pipeline CI/CD para builds automatizados
- Testes unitários no backend
- Suporte a mais idiomas (espanhol, francês)
- Exportação de conversas em PDF

## v2.0 — Visão de Longo Prazo

- 🌐 **Modo servidor** — BMO acessível via rede local
- 📱 **Cliente mobile** — App complementar para celular
- 🧩 **Plugin system** — Skills e ferramentas por plugin
- 🗂️ **Múltiplos perfis** — Diferentes configurações por usuário
- 🤖 **Agentes autônomos** — Tarefas programadas sem supervisão
